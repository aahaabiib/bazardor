# বাজার দর | Bazar Dor

প্রয়োজনীয় পণ্যের দাম এক নজরে ।

## Description

Bazar Dor is a modern, responsive web application that shows daily market prices of essential commodities in Bangladesh like rice, lentils, oil, vegetables, fish, meat, eggs, spices, etc. Users can view price changes, compare markets, and track rising/falling items.

## Technologies Used

- **Next.js** 
- **React** 
- **Tailwind CSS** + DaisyUI
- **react-hot-toast** 
- External Market Price API

## Key Features

1. **Live Price Ticker** 
— Infinite scrolling marquee showing product name, price & change %

2. **Rising & Falling Sections** 
— Top 6 products that went up/down today

3. **Category Filtering** 
— Browse by চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, মসলা

4. **Product Details** 
— Min/Max/Avg price + market-wise price table

5. **Sort by Price** 
— Low to High / High to Low with proper numeric sorting

6. **Auth System** 
— Sign In / Sign Up / Profile / Update Name
    
7. **Fully Responsive** 
— Mobile, Tablet & Desktop

8. **Skeleton Loaders + Toast Notifications**

9. **404 Page** for invalid routes

10. **Bengali Numerals & Date** throughout the UI
